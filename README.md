# 📱 Innovamed Procedimentos - Aplicativo Mobile (.NET MAUI)

Aplicativo mobile Android desenvolvido em **.NET MAUI** utilizando **C#**, integrado com base de dados local **SQLite** para armazenamento e sincronizado com planilhas **Excel/XLSX**[cite: 2].

## 🛠️ Arquitetura Atual e Tecnologias

| Camada | Tecnologia | Função |
| :--- | :--- | :--- |
| **Aplicativo mobile** | .NET MAUI 10 | Criação do aplicativo Android |
| **Linguagem** | C# | Lógica do programa |
| **Interface** | XAML + .NET MAUI | Telas, campos, botões e listas |
| **Banco de dados** | SQLite | Armazenamento local dos procedimentos |
| **Acesso ao SQLite** | sqlite-net-pcl | Comunicação entre C# e SQLite |
| **Banco original** | Excel/XLSX | Fonte dos seus procedimentos |
| **Plataforma** | Android | Sistema operacional do aplicativo |
| **IDE** | Visual Studio / VS Code | Desenvolvimento, compilação e depuração |

## 🚀 Funcionalidades
- Interface multiplataforma moderna construída em XAML e .NET MAUI[cite: 2].
- Persistência de dados local rápida e eficiente utilizando SQLite[cite: 2].
- Leitura e processamento de dados baseados em fontes externas em Excel/XLSX[cite: 2].
